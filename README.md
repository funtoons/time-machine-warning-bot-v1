One line, 120 characters max: the funniest warning label for a time machine. The joke turns the oldest time-travel hazard — meddling with the past — into the punchline, delivered deadpan like a real safety notice, with the surprise saved for the last few words.

`main.py` (stdlib only, deterministic, offline) writes the single label to `/output/entry.txt`.

## The label

> WARNING: Do not change the past. You are the reason it went wrong the first time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
